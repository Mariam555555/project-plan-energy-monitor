Smart Home Energy Monitor

Graduation Project Presentation

What Problem Are We Solving?

  • Electricity consumption generates a continuous flow of data from many households and appliances, making real-time processing challenging.
  • Traditional processing methods struggle to efficiently handle the large volume of continuous IoT data.
  • As the number of households, devices, and readings increases, the system must scale while maintaining reliable performance.

Therefore: A scalable real-time streaming system is needed to collect, process, and analyze electricity consumption data from multiple sources.

Our Solution

A scalable web-based real-time streaming system for collecting, processing, storing, and analyzing electricity consumption data from multiple households and appliances.

The system provides:

  • Real-time data ingestion from multiple IoT devices and households.
  • Scalable stream processing through distributed messaging and processing.
  • Continuous analysis of appliance- and household-level consumption data.
  • Centralized storage of processed historical data for queries and reports.
  • Real-time monitoring and visualization through a web-based dashboard.

Dataset

REFIT Cleaned Dataset

We use the REFIT Cleaned Dataset as the main source of electricity measurements. It provides:

  • Household electricity measurements.
  • Appliance-level data.
  • Time-based consumption records.

The dataset allows us to build and test a realistic electricity monitoring pipeline.

Hardware Simulation Layer

Mapping & Replay

  • Mapping Registry: Connects households with their devices.
    • H001 ➔ Devices | H002 ➔ Devices | H003 ➔ Devices
  • Replay: Replays historical REFIT measurements as continuous streaming events. Generates a continuous data flow that represents real-time electricity consumption.

Streaming & Processing

  • Apache Kafka: Acts as the scalable streaming layer. Transfers incoming events to the processing layer.

  • Processing Layer: Transforms and aggregates the incoming events to generate useful metrics such as:
    • Energy consumption & Device-level consumption
    • Daily and Monthly consumption & Electricity cost

Budget & Alerts

Smart Budget Monitoring

  • Users can set: Daily Budget, Monthly Budget.
  • The system monitors consumption and estimates whether the user is likely to exceed the selected budget.

Example: Daily Budget: 20 EGP | Expected Cost: 22 EGP ➔ ⚠️ Budget Warning

The system can also recommend actions such as reducing the usage of high-consuming appliances.
